# Creative process — provisional, not a diagnosis
This file records **work methods**, not personal medical history. Keep private health discussions out of the public portfolio repository.

## Working hypothesis
Creative work may start with an **affective target** (desired emotional encounter), not a complete mental image. Visible fragments allow recognition, iteration, and composition. In productive flow, evaluation and connection of **external** material seem to accelerate more than internal image vividness. These are self-reported observations, not measured cognitive findings or permanent labels.

## Loop
**Feeling → external fragment → recognition → transformation → relationship → composition → critique → encounter.**
Nonlinear; return to feeling as needed. Don't demand complete visualization before beginning.

### Explore mode
- Capture fragments immediately as a sketch, component, diagram, sentence, or recording.
- Generate alternatives without polishing prematurely.
- Save snapshots / variants; don't depend on memory to reconstruct promising paths.
- Study references for compositional operations, not motifs.
- Allow bottom-up object exploration *or* top-down emotional encounter, depending on the problem.
- Preserve the defining idea when simplifying execution.

### Critique mode
- What is the work actually saying or revealing?
- Does the first encounter evoke curiosity without needing to recognize influences?
- Do details have causal, structural, historical, expressive, or functional roles?
- Does each exceptional detail improve the whole?
- Is the representation truthful and comprehensible?
- What is the **single highest-impact** defect? Fix that first.
- Is dissatisfaction conceptual, executional, or just overexposure to the artifact?
- Test reactions with actual viewers; imagined reactions are not evidence.

### Finish mode
- Lock scope and preserve unused discoveries in an archive.
- New ideas must earn their cost against deadline and purpose.
- Deliver a complete, inspectable vertical slice rather than endlessly refining isolated pieces.
- Document known limitations rather than disguising them.

## Guardrails
Taste can exceed current execution; don't use an imaginary unconstrained future self as a production benchmark. Use the question: *What would a more capable version of me prioritize within these actual constraints?* External cognition is a useful design hypothesis, not evidence of a neurological condition. Avoid making altered states a prerequisite for creative output.
